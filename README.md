# Explore
Kickoff repository to add initial exploratory work

## ai1-satellite

Interactive studies of SpaceX's AI1 compute satellite, live at https://ai1-studies.vercel.app

- `ai1-satellite/satellite-anatomy/`: the satellite's parts and how its onboard AI chips interact
- `ai1-satellite/anatomy/`: the same satellite as an isometric anatomy-kit figure (draft, built with `node build.mjs --auto`)
- `ai1-satellite/cluster-formations/`: how a cluster of AI1 satellites should fly in a 600 km dawn-dusk orbit

Plain static HTML, no build step. Vercel serves `ai1-satellite/` as the site root.
